ⓘ Como usar e compartilhar

1. Personalize e pratique

Use seu perfil, crie matérias e resumos, marque módulos concluídos e gere perguntas a partir de textos.

2. Faça cópias de segurança

Seus dados ficam no armazenamento local do navegador. Use o botão Backup para exportar ou importar. Não limpe dados do site antes de exportar.

3. Publique seu HTML

O arquivo funciona como um site estático e pode ser publicado pelo GitHub Pages. Não exige API paga.

4. Entenda as limitações

O gerador de perguntas usa regras de texto e não uma IA generativa. O editor não oferece autenticação segura nem sincronização automática de alterações entre alunos.
